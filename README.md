# 📊 Job Application Tracker

A full-stack web application built with Flask and SQLite that allows users to track, update, and manage job applications efficiently.

---

## 🚀 Features

- Add job applications
- Update job status (Pending, Applied, Interview, Rejected)
- Delete jobs
- Search jobs by company or role
- Filter jobs by status
- Persistent storage using SQLite database
- Clean and responsive UI

---

## 🛠️ Tech Stack

- Python (Flask)
- SQLite (Database)
- HTML & CSS (Frontend)
- Gunicorn (Deployment server)
